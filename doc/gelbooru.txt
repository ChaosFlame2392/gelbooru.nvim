1. INTRODUCTION                                         *gelbooru-introduction*

gelbooru.nvim is a fast, asynchronous Gelbooru client built for Neovim. It
features a debounced, bucket-indexed autocomplete tag picker, instant image
rendering powered by snacks.nvim, persistent search history, and automated
tag learning.

==============================================================================
2. REQUIREMENTS                                         *gelbooru-requirements*

- Neovim 0.9.0 or higher
- snacks.nvim (with snacks.image enabled)
- ImageMagick (`magick` executable in system PATH, required by snacks.image)
- curl

3. SETUP & CONFIGURATION                               *gelbooru-configuration*

Create ~/.config/nvim/gelbooru_auth.json with your API credentials:
>json
    {
      "api_key": "YOUR_API_KEY",
      "user_id": "YOUR_USER_ID"
    }
<

Configure via Lazy.nvim:
>lua
    return {
      "ChaosFlame2392/gelbooru.nvim",
      dependencies = { "folke/snacks.nvim" },
      cmd = { "Gelbooru", "GelbooruTags" },
      opts = {
        save_dir = "~/Pictures/Gelbooru",
        per_page = 42,
        prefetch_radius = 5,
        enable_logging = true,
        log_level = "DEBUG",
      },
    }
<

Configuration Options:                                  *gelbooru-options*

save_dir                                (string, default: "~/Pictures/Gelbooru")
    Directory path where full-resolution downloaded images are saved.

auth_file           (string, default: stdpath("config") .. "/gelbooru_auth.json")
    Path to your JSON credentials file containing "api_key" and "user_id".

tags_dir              (string, default: "~/.local/share/nvim/gelbooru")
    Directory where split tag databases (series, characters, artists, general)
    are downloaded and cached.

cache_dir                               (string, default: "/tmp/gelbooru_cache")
    Temporary directory used for cached image preview downloads.

enable_logging                                         (boolean, default: true)
    Whether debug logging to disk is enabled. Set to false to disable all
    logging and prevent log file creation.

log_level                                            (string, default: "DEBUG")
    Minimum severity level for logging. Supported values:
    "DEBUG", "INFO", "WARN", "ERROR", or "OFF" (disables logging).

log_file               (string, default: stdpath("state") .. "/gelbooru.log")
    Filesystem destination path for plugin log entries.

per_page                                                  (number, default: 42)
    Number of post results to fetch per page from the Gelbooru API.

prefetch_radius                                            (number, default: 5)
    Number of adjacent posts ahead and behind the active cursor to prefetch
    in the background.

show_tags_in_list                                     (boolean, default: false)
    Whether to display raw tag strings directly inside the list view buffer.

api_base                                                               (string)
    Base Gelbooru posts API endpoint URL.

tags_api                                                               (string)
    Base Gelbooru tags API endpoint URL.

Note: All option keys may be specified in either snake_case or UPPER_CASE.

4. COMMANDS                                                 *gelbooru-commands*

:Gelbooru                                                           *:Gelbooru*
    Open the tag search picker and image browser.

:GelbooruTags                                                   *:GelbooruTags*
    Download and build the local Gelbooru tag database for autocomplete.

==============================================================================
5. KEYMAPS                                                   *gelbooru-keymaps*

Input Buffer:
    <CR>            Submit search query
    <Down>, <C-n>   Navigate down autocomplete list
    <Up>, <C-p>     Navigate up autocomplete list
    <Space>         Accept selected autocomplete suggestion
    <Esc>           Close Gelbooru / exit input to list view

List Buffer:
    j / k           Navigate next / previous post
    <CR>            Download & save current full-resolution image
    <Tab>           Fetch next page of results
    <S-Tab>         Fetch previous page of results
    r               Force re-render current image
    R               Force re-download and re-render current image
    [               Navigate backward in search history
    ]               Navigate forward in search history
    /               Focus search bar to edit query
    q, <Esc>        Close Gelbooru
